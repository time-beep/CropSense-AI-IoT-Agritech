# CropSense — AI + IoT Smart Crop Health Monitoring System

## Overview
CropSense is an AI + IoT based smart agriculture system developed during a 24-hour hackathon.

The system monitors:
- Soil moisture
- Temperature
- Humidity
- Ambient light
- Leaf health using NIR sensing

It provides:
- Real-time monitoring dashboard
- OLED status display
- Telegram alerts for critical conditions
- Crop recommendations
- Stress analysis

---

## Features
- ESP32 based monitoring system
- Real-time sensor analysis
- NIR differential method for leaf health detection
- OLED live status display
- Telegram alert integration
- Web dashboard for monitoring
- Boot self-test system
- AI-assisted crop recommendations

---

## Hardware Used
- ESP32
- DHT11/DHT22
- Soil moisture sensor
- LDR/light sensor
- NIR LED + photodiode
- OLED display
- ADS1115 ADC
- Buzzer + LEDs

---

## Software Stack
- Arduino IDE
- ESP32
- Python/React
- Telegram Bot API

---

## How It Works
1. Sensors collect environmental data.
2. ESP32 processes readings.
3. NIR differential detects plant stress.
4. OLED displays system status.
5. Dashboard visualizes live data.
6. Telegram alerts trigger during WARNING/CRITICAL conditions.
